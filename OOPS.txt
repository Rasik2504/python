# ============================================================
# 1. ABSTRACTION
# ============================================================

# EASY:
# Create an abstract class Animal with an abstract method sound().
# Create Dog and Cat classes that implement sound().

# MEDIUM:
# Create an abstract class Shape with an abstract method area().
# Create Circle, Rectangle, and Triangle classes.
# Each class should calculate its own area.

# HARD:
# Create an abstract Payment class with pay(amount) and refund(amount).
# Create UPI, CreditCard, and NetBanking classes.
# Create a function that can process any payment object.
